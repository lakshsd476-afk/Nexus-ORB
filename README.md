## ✨ Features

- **📚 Extensive Prompt Library** – 35+ curated prompts across categories like Coding, Core Engineering, Projects, Exams, and more.
- **⚡ Instant Execution** – Run any prompt with your own inputs via Groq's lightning‑fast Llama 3.1 API.
- **🛡️ Built‑in Prompt Analysis** – Get a heuristic quality score and AI‑powered feedback on your prompt's structure, clarity, and safety.
- **🔍 Dual Evaluation** – Automatic heuristic scoring + optional deep AI evaluation for expert insights.
- **🎨 Futuristic UI** – Glass‑morphism cards, animated starfield, pulsing colour‑cycling orb, and smooth scroll‑triggered animations.
- **📂 Add & Export** – Easily add your own prompts and export the entire library as JSON.
- **🖥️ Fully Responsive** – Works seamlessly on desktop and tablet.
- **🌐 Free & Open‑Source** – MIT licensed, powered by free Groq API and Streamlit Community Cloud.
